# ByteSpace New

Figma-matched learning platform built with Next.js, Tailwind CSS, and DaisyUI.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Demo login: `demo@bytespace.com` / `demo123`

## Reviewer notes

- Landing page follows the ByteSpace New Figma (hero through footer).
- Bonus: login, signup, course catalog, course details, creator profile, 404.
- App API routes live under `/api` so the site can deploy on Vercel without a separate Express host.
